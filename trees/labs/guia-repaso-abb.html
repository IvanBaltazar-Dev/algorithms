1. Ejercicio resuelto — usa Pila

Laboratorio 4 (2024-2) · Pregunta 2 · "Vitivinícola"   INF27 · profesores Ana Roncal, F. Huamán, D. Allasi, R. Cueva, H. Sánchez.

Enunciado (resumen)

Una empresa vitivinícola guarda su almacén en un ABB ordenado por el año del lote (clave = año tipo 2018; dato = cantidad de botellas, < 1000). Todas las botellas de un mismo año se juntan en un solo lote sumando la cantidad.

  • a) (3 pts) ingresa_lote: inserta un lote nuevo, o si el año ya existe, solo actualiza (suma) su cantidad.
  • b) (7 pts) reporte de stock en orden descendente por año. Debe ser totalmente iterativo (si no, no vale). Solo puede usar una pila o cola auxiliar, y esa pila/cola solo recibe datos, no nodos del árbol.

Árbol de ejemplo y salida esperada del reporte descendente:

            2018-100
           /        \
      2011-150      2022-50
      /      \       /      \
 2010-175  2017-25  2019-125  2023-200
                       \
                     2020-75

Reporte (mayor a menor año):
2023-200  2022-50  2020-75  2019-125  2018-100  2017-25  2011-300  2010-175

(El 2011-300 del reporte refleja el estado tras un ingresa_lote que acumuló stock en 2011; lo que se evalúa es el orden, que sí coincide.)

Auxiliar necesaria: buscarNodo (retorna el puntero al nodo)

La librería trae buscar() que devuelve bool — no sirve para modificar ni navegar. Necesitas una que devuelva el Nodo*. El enunciado permite "los auxiliares que necesite".

// Devuelve el puntero al nodo cuya clave (numero) es igual a "clave",
// o nullptr si no existe. Aprovecha el orden del ABB (no recorre todo).
NodoArbolBinarioBusqueda* buscarNodo(NodoArbolBinarioBusqueda *nodo, int clave) {
    if (esNodoVacio(nodo)) return nullptr;
    if (nodo->elemento.numero == clave) return nodo;
    if (clave < nodo->elemento.numero)
        return buscarNodo(nodo->izquierda, clave);
    else
        return buscarNodo(nodo->derecha, clave);
}

Parte a) ingresa_lote — insertar o actualizar

// Estrategia: primero busco si el año ya existe en el ABB.
// Si existe, solo sumo la cantidad al lote (no inserto nodo nuevo).
// Si no existe, uso el insertar de la libreria (ordena por numero=año).
void ingresa_lote(ArbolBinarioBusqueda &arbol, int anio, int cantidad) {
    NodoArbolBinarioBusqueda *nodo = buscarNodo(arbol.raiz, anio);
    if (nodo != nullptr)
        nodo->elemento.cantidad += cantidad;   // el año ya existe: acumulo stock
    else
        insertar(arbol, {anio, cantidad});     // año nuevo: inserto un nodo
}

Parte b) reporte descendente — iterativo con Pila

Descendente en un ABB = recorrido en orden inverso: derecha → nodo → izquierda. Es el inorden iterativo, pero bajando por la derecha en vez de la izquierda.

// Estrategia: recorrido en orden inverso (der, nodo, izq) de forma
// iterativa con una Pila. Bajo por la DERECHA apilando; cuando ya no
// puedo bajar, desapilo (ese es el mayor pendiente), lo muestro, y
// sigo por su IZQUIERDA. La pila guarda solo el año, no el nodo.
void reporteDescendente(const ArbolBinarioBusqueda &arbol) {
    Pila pila;
    construir(pila);
    NodoArbolBinarioBusqueda *actual = arbol.raiz;

    while (actual != nullptr || not esPilaVacia(pila)) {
        // 1) Bajo por la DERECHA apilando solo la clave (año)
        while (actual != nullptr) {
            ElementoPila dato;
            dato.numero = actual->elemento.numero;
            apilar(pila, dato);
            actual = actual->derecha;
        }
        // 2) Saco el año del tope y re-ubico el nodo real desde la raíz
        //    (la pila solo guarda datos, por eso lo vuelvo a buscar)
        int anio = desapilar(pila).numero;
        actual = buscarNodo(arbol.raiz, anio);
        // 3) Muestro el lote: año-cantidad
        cout << actual->elemento.numero << "-" << actual->elemento.cantidad << "  ";
        // 4) Continúo por la IZQUIERDA
        actual = actual->izquierda;
    }
}

main de prueba

int main() {
    ArbolBinarioBusqueda arbol;

    ingresa_lote(arbol, 2018, 100);
    ingresa_lote(arbol, 2011, 150);
    ingresa_lote(arbol, 2022, 50);
    ingresa_lote(arbol, 2010, 175);
    ingresa_lote(arbol, 2017, 25);
    ingresa_lote(arbol, 2019, 125);
    ingresa_lote(arbol, 2023, 200);
    ingresa_lote(arbol, 2020, 75);

    reporteDescendente(arbol); cout << endl;
    return 0;
}
Por qué funciona (para el comentario que exige el profesor): el recorrido en orden de un ABB entrega las claves ordenadas; si en vez de izq–nodo–der hago der–nodo–izq, salen de mayor a menor. La pila me guarda el "camino de regreso" mientras bajo por la derecha. Como esta librería de Pila solo almacena enteros (ElementoPila = {numero, tipo}), guardo el año y re-ubico el nodo con buscarNodo — cumpliendo "solo datos, no nodos".

minimoArbol

// Devuelve el nodo con la clave MÁS PEQUEÑA del (sub)árbol.
// En un ABB el mínimo siempre está en el extremo izquierdo:
// bajo por ->izquierda hasta que ya no haya hijo izquierdo.
NodoArbolBinarioBusqueda* minimoArbol(NodoArbolBinarioBusqueda *nodo) {
    if (esNodoVacio(nodo)) return nodo;             // árbol vacío: no hay mínimo
    if (esNodoVacio(nodo->izquierda)) return nodo;  // sin hijo izq: este es el mínimo
    return minimoArbol(nodo->izquierda);            // sigo bajando a la izquierda
}

insertarRecursivo

// El *& (puntero por referencia) es clave: permite que cuando plante
// un nodo nuevo, el hijo del padre apunte realmente a él.
void insertarRecursivo(NodoArbolBinarioBusqueda *&raiz, const ElementoArbolBinarioBusqueda &elemento) {
    if (esNodoVacio(raiz))
        plantarNodoArbolBinario(raiz, nullptr, elemento, nullptr); // hueco: planto aquí
    else if (raiz->elemento.numero > elemento.numero)
        insertarRecursivo(raiz->izquierda, elemento);   // menor: voy a la izquierda
    else if (raiz->elemento.numero < elemento.numero)
        insertarRecursivo(raiz->derecha, elemento);     // mayor: voy a la derecha
    else
        cout << "El elemento ya se encuentra" << endl; // igual: no se duplica
}

buscarRecursivo

bool buscarRecursivo(NodoArbolBinarioBusqueda *nodo, const ElementoArbolBinarioBusqueda &elemento) {
    if (esNodoVacio(nodo)) return false;                 // llegué a vacío: no está
    if (nodo->elemento.numero == elemento.numero) return true;
    if (elemento.numero < nodo->elemento.numero)
        return buscarRecursivo(nodo->izquierda, elemento);
    else
        return buscarRecursivo(nodo->derecha, elemento);
}

eliminarRecursivo — los 3 casos

NodoArbolBinarioBusqueda* eliminarRecursivo(NodoArbolBinarioBusqueda *nodo,
                                            const ElementoArbolBinarioBusqueda &elemento) {
    if (esNodoVacio(nodo)) return nodo;                  // no se encontró
    if (nodo->elemento.numero > elemento.numero)
        nodo->izquierda = eliminarRecursivo(nodo->izquierda, elemento);
    else if (nodo->elemento.numero < elemento.numero)
        nodo->derecha = eliminarRecursivo(nodo->derecha, elemento);
    else {
        // ENCONTRADO. Casos 1 y 2: cero o un solo hijo
        if (esNodoVacio(nodo->izquierda)) {
            NodoArbolBinarioBusqueda *hijo = nodo->derecha;
            delete nodo;
            return hijo;                                 // sube el hijo derecho (o nullptr)
        }
        if (esNodoVacio(nodo->derecha)) {
            NodoArbolBinarioBusqueda *hijo = nodo->izquierda;
            delete nodo;
            return hijo;                                 // sube el hijo izquierdo
        }
        // Caso 3: dos hijos -> reemplazo con el sucesor (mínimo del subárbol derecho)
        NodoArbolBinarioBusqueda *suc = minimoArbol(nodo->derecha);
        nodo->elemento = suc->elemento;                  // copio el valor del sucesor
        nodo->derecha = eliminarRecursivo(nodo->derecha, suc->elemento); // y lo borro
    }
    return nodo;
}

Recorridos (los 3 DFS)

// Preorden (raíz, izq, der): sirve para reconstruir/copiar un árbol
void preOrden(NodoArbolBinarioBusqueda *nodo) {
    if (esNodoVacio(nodo)) return;
    imprimirNodo(nodo);                 // <- raíz primero
    preOrden(nodo->izquierda);
    preOrden(nodo->derecha);
}
// En orden (izq, raíz, der): en un ABB sale ORDENADO de menor a mayor
void enOrden(NodoArbolBinarioBusqueda *nodo) {
    if (esNodoVacio(nodo)) return;
    enOrden(nodo->izquierda);
    imprimirNodo(nodo);                 // <- raíz en medio
    enOrden(nodo->derecha);
}
// Postorden (izq, der, raíz): sirve para eliminar/liberar (hijos antes que el padre)
void postOrden(NodoArbolBinarioBusqueda *nodo) {
    if (esNodoVacio(nodo)) return;
    postOrden(nodo->izquierda);
    postOrden(nodo->derecha);
    imprimirNodo(nodo);                 // <- raíz al final
}

altura y esEquilibrado

// Altura en ESTA librería: vacío = 0, hoja = 1 (ojo, en otras es -1 / 0)
int alturaRecursivo(NodoArbolBinarioBusqueda *nodo) {
    if (esNodoVacio(nodo)) return 0;
    if (esNodoVacio(nodo->izquierda) && esNodoVacio(nodo->derecha)) return 1;
    return 1 + maximo(alturaRecursivo(nodo->izquierda), alturaRecursivo(nodo->derecha));
}
// Equilibrado: en CADA nodo, la diferencia de alturas de sus ramas es <= 1
bool esEquilibradoRecursivo(NodoArbolBinarioBusqueda *nodo) {
    if (esNodoVacio(nodo)) return true;
    int hi = alturaRecursivo(nodo->izquierda);
    int hd = alturaRecursivo(nodo->derecha);
    return abs(hi - hd) <= 1
        && esEquilibradoRecursivo(nodo->izquierda)
        && esEquilibradoRecursivo(nodo->derecha);
}

// contar nodos
int numeroNodos(NodoArbolBinarioBusqueda *nodo) {
    if (esNodoVacio(nodo)) return 0;                  // neutro
    return 1 + numeroNodos(nodo->izquierda) + numeroNodos(nodo->derecha);
}

// sumar valores (aquí sumo las cantidades de todos los lotes)
int sumarCantidades(NodoArbolBinarioBusqueda *nodo) {
    if (esNodoVacio(nodo)) return 0;
    return nodo->elemento.cantidad
         + sumarCantidades(nodo->izquierda)
         + sumarCantidades(nodo->derecha);
}

// contar hojas
int numeroHojas(NodoArbolBinarioBusqueda *nodo) {
    if (esNodoVacio(nodo)) return 0;
    if (esNodoVacio(nodo->izquierda) && esNodoVacio(nodo->derecha)) return 1; // es hoja
    return numeroHojas(nodo->izquierda) + numeroHojas(nodo->derecha);
}

// contar los que cumplen X  (ej.: lotes con cantidad mayor a un umbral)
int contarStockAlto(NodoArbolBinarioBusqueda *nodo, int umbral) {
    if (esNodoVacio(nodo)) return 0;
    int yo = (nodo->elemento.cantidad > umbral) ? 1 : 0;   // ¿este nodo cumple?
    return yo + contarStockAlto(nodo->izquierda, umbral)
             + contarStockAlto(nodo->derecha, umbral);
}

4. Plantillas iterativas (Pila y Cola)

Inorden iterativo con Pila (sale ordenado ascendente)

void inordenIterativo(const ArbolBinarioBusqueda &arbol) {
    Pila pila; construir(pila);
    NodoArbolBinarioBusqueda *actual = arbol.raiz;
    while (actual != nullptr || not esPilaVacia(pila)) {
        while (actual != nullptr) {                  // bajo apilando por la IZQUIERDA
            ElementoPila d; d.numero = actual->elemento.numero;
            apilar(pila, d);
            actual = actual->izquierda;
        }
        int clave = desapilar(pila).numero;
        actual = buscarNodo(arbol.raiz, clave);
        imprimirNodo(actual);                        // proceso
        actual = actual->derecha;                     // sigo por la DERECHA
    }
}

Preorden iterativo con Pila

void preordenIterativo(const ArbolBinarioBusqueda &arbol) {
    if (esArbolVacio(arbol)) return;
    Pila pila; construir(pila);
    ElementoPila r; r.numero = arbol.raiz->elemento.numero;
    apilar(pila, r);
    while (not esPilaVacia(pila)) {
        int clave = desapilar(pila).numero;
        NodoArbolBinarioBusqueda *nodo = buscarNodo(arbol.raiz, clave);
        imprimirNodo(nodo);                          // proceso la raíz primero
        // apilo DERECHA y luego IZQUIERDA (para sacar la izquierda antes)
        if (nodo->derecha != nullptr)   { ElementoPila d; d.numero = nodo->derecha->elemento.numero;   apilar(pila, d); }
        if (nodo->izquierda != nullptr) { ElementoPila i; i.numero = nodo->izquierda->elemento.numero; apilar(pila, i); }
    }
}

Por niveles (BFS) con Cola — el truco del "longitud"

void porNiveles(const ArbolBinarioBusqueda &arbol) {
    if (esArbolVacio(arbol)) return;
    Cola cola; construir(cola);
    ElementoCola r; r.numero = arbol.raiz->elemento.numero; encolar(cola, r);
    int nivel = 0;
    while (not esColaVacia(cola)) {
        int n = longitud(cola);                      // cuántos nodos hay en ESTE nivel
        cout << "Nivel " << nivel << ": ";
        for (int i = 0; i < n; i++) {
            int clave = desencolar(cola).numero;
            NodoArbolBinarioBusqueda *nodo = buscarNodo(arbol.raiz, clave);
            imprimirNodo(nodo);
            if (nodo->izquierda != nullptr) { ElementoCola e; e.numero = nodo->izquierda->elemento.numero; encolar(cola, e); }
            if (nodo->derecha != nullptr)   { ElementoCola e; e.numero = nodo->derecha->elemento.numero;   encolar(cola, e); }
        }
        nivel++; cout << endl;
    }
}
Dos avisos para el examen:
  • Los campos del elemento de Pila/Cola dependen de la librería que te den. En la que revisé, ElementoPila = {numero, tipo} y ElementoCola a veces usa codigo en vez de numero. Revisa el nombre exacto del campo antes de compilar.
  • Aquí re-ubico el nodo con buscarNodo porque esta Pila/Cola solo guarda enteros. Si tu librería permite guardar un puntero al nodo, guárdalo directo y te ahorras el buscarNodo (queda O(n) en vez de O(n·log n)).
